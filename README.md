# NikitaCrafts v8

A self-contained mobile voxel sandbox for GitHub Pages.

## Important
- No Three.js, CDN, module import, or external JavaScript dependency.
- Open `index.html` directly or host the folder on GitHub Pages.
- New World uses a deterministic seed.
- Continue restores the locally saved world when available.
- iPhone landscape is recommended.

## Controls
- Left joystick: move
- Swipe right side: look
- ↑: jump
- ⛏: mine
- +: place
- Hotbar: select block
- Desktop: WASD / Space / F / G

## GitHub Pages
Replace the old site files with `index.html`, `style.css`, and `game.js` from this ZIP. Do not keep the old `game.js` or Three.js files mixed into the site.
